# AfterCopy

A mobile-first prototype for post-assignment decompression and reflection for journalists after difficult stories.

## Open It

Double-click `index.html`, or run a local server from this folder:

```powershell
node server.mjs
```

Then open:

```text
http://127.0.0.1:4821/
```

## Included

- Local login screen
- Assignment completion log
- Guided post-assignment debrief
- Burnout and distress self-check
- 24-hour, 72-hour, and 7-day private reminder queue
- Recovery plan builder
- Footage review safety prompt
- Private AI-style reflection prompt generator
- Optional private notes captured with each debrief
- One in-app wellness report generated from saved inputs
- Copy-paste LLM prompt for generating a comprehensive wellness plan or Word-ready record
- Private pattern summary
- Browser-only local storage prototype

## Prototype Safeguards

AfterCopy uses non-diagnostic language, includes redaction reminders, keeps journals personal by default, and frames AI prompts as reflection support rather than therapy.
